## 4. 采购与验证建议

1. 先买 USB 3 声道 DAC + TPA3116 2.1 功放，成本最低、最容易验证；
2. 蓝牙、模拟输入先用板载 AP6354/ALC5651 验证；
3. 5.1 升级时优先换 USB 6/8 声道 DAC，功放可逐步补齐；
4. 所有器件优先选择 Linux 下免驱或内核已支持的型号。
