# 开发路线图

## 总体目标

以 RK3399 完成 2.1 全链路验证，沉淀一套可扩展到 5.1/7.1、可更换 SoC 的音频系统架构与软件框架。

## M0：文档与架构（当前）

**交付物**

- 系统架构文档（`docs/architecture.md`）；
- 音频管线定义（`docs/audio_pipeline.md`）；
- 声道映射规范（`docs/channel_mapping.md`）；
- 配置规范（`docs/config_spec.md`）；
- 硬件平台说明（`docs/hardware_rk3399.md`）。

**退出条件**：文档评审通过，2.1 配置与管线定义一致，测试可运行。

## M1：2.1 软件验证（PC）

**交付物**

- 测试音生成脚本；
- CamillaDSP 配置（回环 / stdin / 文件 / USB）；
- 信号链参考模拟与自动化测试。

**当前状态**：基本完成（`scripts/`、`tests/`、`configs/`）。

**退出条件**：`bash scripts/run_validation.sh` 通过；声道路由（L/R/SUB）测试全部通过。

## M2：RK3399 平台接入

**交付物**

- 系统烧录、ALSA 设备确认；
- iTOP Ubuntu 20.04 LTS arm64 无桌面版 rootfs + 厂商 BSP 内核（系统选型见 `docs/linux_os_selection.md`）；
- SDK 板级 bring-up：内核/dts 适配 AP6354、WiFi/BT 驱动与固件、snd-aloop 开启（见 `docs/rk3399_sdk_bringup.md`）；
- USB 声卡输出验证；
- AP6354 蓝牙 A2DP 接入；
- ALC5651 模拟 Line-in 接入；
- CamillaDSP 在板卡上常驻运行。

**退出条件**：三种输入源均可到达 2.1 输出；声道顺序正确；连续播放无爆音。

## M3：2.1 硬件与调音

**交付物**

- TPA3116 2.1 功放与扬声器系统；
- 电源、散热、开关机时序；
- 测量与调音流程（频响、分频、延迟、限幅）；
- 预设（音乐/电影/夜间）。

**退出条件**：REW 测量达标（±3dB、THD+N < 0.1% 等），听感验收通过。

## M4：产品化完善

**交付物**

- 配置管理器与 profile 生成；
- Web UI / REST API；
- 红外、按键、LED；
- systemd 服务、看门狗、日志；
- 固件/配置升级机制。

**退出条件**：非技术用户可完成音源切换、音量、预设操作；异常可自动恢复。

## M5：5.1 升级

**交付物**

- 6/8 声道输出（USB 或 I2S TDM DAC）；
- 5.1 声道映射与测试音；
- Bass Management 扩展到 5.1；
- 5.1 原生 PCM 直通与 stereo 上混（可选）；
- HDMI ARC/eARC 输入（硬件具备后）。

**退出条件**：5.1 各声道路由、分频、延迟对齐验收通过；2.1 功能回归不受影响。

## M6：7.1 / 7.1.4 与换芯

**交付物**

- 8/16 声道输出；
- 7.1/7.1.4 映射与空间声学处理；
- 新 SoC 平台移植文档与驱动适配。

**退出条件**：在目标平台跑通相同 profile；应用层代码零改动或仅配置级改动。

## 版本与分支

| 分支 | 用途 |
| --- | --- |
| `main` | 稳定版本 |
| `theater_2.1_V1.0` | 当前 2.1 开发分支 |
| `feat/*` / `docs/*` / `fix/*` | 功能、文档、修复分支 |

2.1 验证通过后：合并到 `main`，打 `v1.0.0` 标签，再开 `theater_5.1_V2.0` 分支。
