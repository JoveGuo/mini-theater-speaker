# 测量与验收方法

## 1. 工具

- 测量麦克风：miniDSP UMIK-1（带校准文件）或同类；
- 测量软件：REW；
- 万用表、示波器（可选，用于电源与功放验证）；
- 3.5mm / RCA / XLR 线材；
- 已知内容的测试音：`assets/test_tones/`（仓库已生成）。

## 2. 频响测量

1. 将测量麦放在听音位，高度与耳朵齐平，距离回音壁约 1m；
2. 在 REW 中生成 20Hz-20kHz 对数扫频，通过 CamillaDSP 输出到功放；
3. 分别测量 FL、FR、SUB 三路，记录原始频响；
4. 在 CamillaDSP 中导入 REW 生成的 EQ 或自行添加 Peaking 滤波，目标 20Hz-20kHz ±3dB；
5. 测量后复核相位和群延迟，避免过度 EQ。

## 3. 分频与相位对齐

1. 以 100Hz 为起点，用 REW 的 All SPL 窗口同时测量卫星和低音炮；
2. 调整分频点，使交叉区域无明显凹陷或隆起；
3. 调整 SUB 延迟，让分频点附近相位对齐；
4. 用 100Hz 正弦和脉冲响应确认衔接。

## 4. 失真与底噪

| 指标 | 目标 |
| --- | --- |
| 1kHz @ 1W THD+N | < 0.1% |
| 无信号底噪 | 30cm 外听不到明显底噪 |
| 最大音量 | 限幅器工作且无明显异常失真 |
| 声道隔离 | 相邻声道串扰 < -40dB（参考） |

## 5. 延迟

1. 用声卡同时回放测试音并录音，测量输入到输出的 DSP 延迟；
2. V1 总延迟目标 ≤ 40ms；
3. 后续低延迟 profile 目标 ≤ 20ms；
4. 若增加 FIR 滤波，需重新测量。

## 6. 长稳与开关机

- 连续播放 24 小时，监控功放散热片温度和 DSP 进程状态；
- 上电、断电、切换输入时不得有爆音；
- 电源和功放余量 ≥ 30%；
- 蓝牙断连/重连、USB 拔插后系统应自动恢复或给出明确状态。

## 7. 声道映射验收

逐通道注入测试音，确认物理扬声器发声位置：

| 测试音 | 预期发声 |
| --- | --- |
| `left_1k.wav` | 左卫星 |
| `right_1k.wav` | 右卫星 |
| `sub_50.wav` | 低音炮 |
| `stereo_1k.wav` | 左右卫星 |
| `sweep_20_20k.wav` | 全链路频响 |
