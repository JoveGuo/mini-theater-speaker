# 测量与验收方法

## 工具

- 测量麦克风，例如 miniDSP UMIK-1
- 免费测量软件 REW
- 带校准文件的麦克风支架或夹具
- 3.5mm / RCA 线材，用于连接声卡和功放

## 频响测量

1. 将麦克风放在听音位，高度与耳朵齐平，距离回音壁约 1m。
2. 在 REW 中生成 20Hz-20kHz 对数扫频，通过 CamillaDSP 输出到功放。
3. 分别测量左卫星、右卫星和低音炮三路，记录原始频响。
4. 在 CamillaDSP 中导入 REW 生成的 EQ 或自行加入 Peaking 滤波，目标为 20Hz-20kHz ±3dB。

## 分频与相位对齐

1. 以 100Hz 为起点，用 REW 的 All SPL 窗口同时测量卫星和低音炮。
2. 调整分频点，使交叉区域没有明显凹陷或隆起。
3. 调整 `delay_sub`，让低音炮与卫星在分频点附近相位对齐。
4. 用 100Hz 正弦和脉冲响应确认衔接。

## 失真与底噪

- 1kHz @1W：THD+N 目标小于 0.1%。
- 输出不接信号时，30cm 外不应听到明显底噪。
- 最大音量播放时，限幅器应工作且没有异常失真。

## 延迟

1. 用声卡同时回放测试音并录音，测量输入到输出的 DSP 延迟。
2. 目标小于 20ms；若后续加入更多 FIR 滤波，需要重新测量。

## 长期与开关机

- 连续播放 24 小时，监控功放散热片温度和保护状态。
- 上电、断电、切换输入时不能有爆音。
- 电源和功放至少保留 30% 余量。
